# Feature 1 - Adding list of items for each account

When the user create/edit new account, adds in a section that allows the user to add in a list of items along with its cost. This should be toggleable as the list can be very expansive. For example, a climbing expense account might have the following items: Chalk, Entry Pass, Sport Tape, Odor Remover, Gym Membership, etc.,

# Feature 2 - Transaction Tracking System

Whenever the user make a deposit/withdraw to any of the account or chain (list of accounts), the system should keep track of those information similarly to a bank transaction. To avoid data retrieval issues. We should differentiate the level of transaction storage as much as possible, start by Year then Month.

## Feature 3 - Transaction Viewing System

The system should dedicate a web page that depicts all transactions the user made over a certain period. There should also include an easy transaction management that allows the user to delete one or a large number of transactions over a certain period (month, year) at a time, to clear up storage space.

## Feature 4 - Transaction Tag

Similarly to account, the user should be able to create various tags and apply them onto the transaction.
