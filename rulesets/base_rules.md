Please follow these rules when implementing new features:
1. Before implement any new features, please layout the implementation plan under "plans" directory,and verify with me, if it's okay to proceed with the plan.
2. If there are any additional actions or resources you need from me, please do let me know.
3. When implementing a new feature, please create a separate branch prior, and I will merge it with the appropriate branch, if I think the implementation is good.
4. After successfully implementing a feature, create a documentation with the "{FEATURE_NAME}.md" inside the docs directory. The documentation should contain the implementation process, the requirement to execute such plan, and the date that the feature was implemented. If the implementation was not successful, and further iteration is needed, please just update the same documentation file, untilit reaches the successful iteration.
5. Use `pnpm` whenever possible.
6. After implementing the application, check for any syntax errors and fix them. 
7. After implementing the application, check for any issues, errors raised by next js and fix them.
8. Create appropriate testcases to test the new feature, if the new feature is replacing existing one, also update the testcases.
9. When you are fixing any problems/issues, remember to apply the rulesets.
10. After you have conducted any fixes, please remember to update the documentation.
11. After finishing the implementation or fixing any features, do a build, before running the application.
12. Reuse existing system functionalities if possible.
13. You may go through the docs folder to learn about the implementation of the projects so far.
14. Remember the rulesets for future implementation for this project.
15. Please also update the import/export system accordingly.
