When implementing new features please follow these principles, whenever possible, if it does not hinder performance:
1. SOLID
2. GRASP
3. Clean Code
4. KISS
5. DRY
6. Use meaningful name

The goal is to create a codebase that is:
1. Maintainable
2. Scalable 
3. Modular
4. Readable 
5. Easily Changed (low coupling and high coherent)
